打开网页后，读取、检查和生成 Excel 都在你的浏览器里完成。服务器只提供网页文件，不处理你的观鸟记录。

1. 选择文件，预览并下载

自动使用你上次保存的对应；首次使用预置 12 条经验规则，X 默认按每条 1 估算并提醒核对。需要调整？到下方搜索、修改或添加鸟名规则。

UTF-8 编码 CSV / TSV；表头须含“鸟种”“观察日期”“地点”，可含“数量”。每个文件仅一次观察。最多 50 个文件，每个不超过 5 MB；更大文件请用下载版。

原始文件不会被修改。不支持英文鸟名自动翻译；斜线种、不确定种和杂交记录需人工处理。

2. 鸟名规则 · 搜索、修改、添加

以下 12 条来自 Joc 原工具的手工积累，仅覆盖他实际遇到的部分差异，不是两套完整名录的官方对照。点击名称即可修改，也可增加或删除规则；删除后该名称会原样保留。

所有对应都需要你确认。尤其银鸥、百灵、毛脚燕等涉及分类范围变化的名称，不能只凭中文名套用；不确定时请删除该规则、保留原名并人工核对。
两边采用什么名录？为什么仍需要人工检查？

中国观鸟记录中心的官方升级通知说明，自 2024 年 1 月 1 日启用《中国鸟类分类与分布名录（第四版）》，即“郑四”。eBird 使用 eBird/Clements 分类体系，并非直接采用 IOC；Cornell 的2026 更新说明发布于 2026 年 11 月 2 日。资料核对日期：2026 年 11 月 7 日。

这份对应表没有完成两套名录的全量、逐种验证，也不会自动处理拆分、合并、亚种、杂交或不确定种。即使学名相同，不同年份的分类范围也可能不同。导入前请以目标平台当前名录核对。

下载版 / 从记录到表格

也可以继续用原下载版。

01

准备中文鸟种导出文件

从 eBird 下载 CSV 或 TSV。检查文件包含“鸟种”等中文列名，且同一文件对应同一次观察。工具不会把英文鸟名自动翻译成中文。

02

解压，放入文件，双击运行

将导出文件放进解压后的工具文件夹，双击“双击转换.command”。首次运行会创建独立 Python 环境，经你确认后从 PyPI 安装 openpyxl。

03

核对 Excel，再导入

检查生成的 .xlsx 中的鸟名和数量，再前往 中国观鸟记录中心 按其当前页面提示导入。日期、地点及完整观察信息仍需自行核对填写。

02 / 少一些手工整理

轻量，也把边界说清。

  • 读取 UTF-8 CSV / TSV，保留鸟种与数量。
  • 清理名称后的附加内容，应用内置中文名称对应规则。
  • 提示空鸟名，过滤“未识别”记录，不编造鸟种。
  • 遇到同名输出自动编号，不覆盖原文件。
  • 遇到格式问题明确提示，避免把错误日期写成今天。
  • 检查日期、地点与开始时间，不擅自合并观察。

常见问题

电脑里没有 Python，怎么办？

上方网页版不需要 Python。若要使用下载版，先从 python.org 安装 Python 3.9 或更新版本，再运行启动器。工具使用自己的虚拟环境，不改系统 Python。

双击后提示没有执行权限？

在终端进入解压目录，运行 chmod +x 双击转换.command。下载包中的 README 也提供直接用终端运行的步骤。不要关闭系统安全保护。

数量是 X，或者鸟名对不上？

X 表示未知数量。网页版默认按每条 1 估算，可在鸟名规则下修改估算值或选择保留为空；原始空值不估算。下载版 v1.5.1 仍把 X 保留为空。数量和名称需在导入前人工核对；名称对应规则仅覆盖部分差异，并不等同于完整分类名录。

能直接导入全年所有记录吗？

请先按同一次观察整理文件。工具会拒绝混合日期或地点的记录，不会擅自合并观察。使用中文列名的单次观察导出最稳妥。
