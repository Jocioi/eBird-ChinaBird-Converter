01 / 从记录到表格

三步，把记录接起来。

01

准备中文鸟种导出文件

从 eBird 下载 CSV 或 TSV。检查文件包含“鸟种”等中文列名，且同一文件对应同一次观察。工具不会把英文鸟名自动翻译成中文。

02

解压，放入文件，双击运行

将导出文件放进解压后的工具文件夹，双击“双击转换.command”。首次运行会创建独立 Python 环境，经你确认后从 PyPI 安装 openpyxl。

03

核对 Excel，再导入

检查生成的 .xlsx 中的鸟名和数量，再前往 中国观鸟记录中心 按其当前页面提示导入。日期、地点及完整观察信息仍需自行核对填写。

02 / 少一些手工整理

轻量，也把边界说清。

  • 读取 UTF-8 CSV / TSV，保留鸟种与数量。
  • 清理名称后的附加内容，应用内置中文名称对应规则。
  • 提示空鸟名，过滤“未识别”记录，不编造鸟种。
  • 遇到同名输出自动编号，不覆盖原文件。
  • 遇到格式问题明确提示，避免把错误日期写成今天。
  • 检查日期、地点与开始时间，不擅自合并观察。

03 / 开始前看一眼

常见问题

电脑里没有 Python，怎么办？

先从 python.org 安装 Python 3.9 或更新版本，再运行启动器。工具使用自己的虚拟环境，不改系统 Python。

双击后提示没有执行权限？

在终端进入解压目录，运行 chmod +x 双击转换.command。下载包中的 README 也提供直接用终端运行的步骤。不要关闭系统安全保护。

数量是 X，或者鸟名对不上？

X 表示没有具体数量，转换时保留为空并提示，不会自动改成 1。数量和名称需在导入前人工核对；名称对应规则仅覆盖部分差异，并不等同于完整分类名录。

能直接导入全年所有记录吗？

请先按同一次观察整理文件。工具会拒绝混合日期或地点的记录，不会擅自合并观察。使用中文列名的单次观察导出最稳妥。
